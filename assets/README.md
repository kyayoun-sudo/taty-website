# Mettre à jour les portraits de l'équipe

Déposez les photos dans le dossier **assets/equipe** de GitHub, puis enregistrez avec **Commit changes** sur `main`.

Le nom du fichier doit reprendre exactement l'identifiant ci-dessous. Choisissez une seule extension par personne : `.jpg`, `.jpeg`, `.png`, `.webp` ou `.avif`.

| Personne | Exemple de fichier |
|---|---|
| TATY Hippolyte Landry | `taty-hippolyte-landry.jpg` |
| OUATTARA Navaga | `ouattara-navaga.jpg` |
| KOUAME Christian | `kouame-christian.jpg` |
| Paul Yann Cédric Komenan | `komenan-paul-yann.jpg` |
| KOUAKOU Charles | `kouakou-charles.jpg` |
| AHO LOYO Melaine | `aho-loyo-melaine.jpg` |
| BEUGRE Stéphane | `beugre-stephane.jpg` |
| KONAN Yannick | `konan-yannick.jpg` |
| KOUYATE Ismaël | `kouyate-ismael.jpg` |
| DAGNOGO Awa | `dagnogo-awa.jpg` |
| KOFFI Auriane | `koffi-auriane.jpg` |
| YOBOUE N'Guessan | `yoboue-nguessan.jpg` |
| SEKA Cédric | `seka-cedric.jpg` |
| KACOU Chimène | `kacou-chimene.jpg` |
| KOFFI Samira | `koffi-samira.jpg` |
| ANDE Yvan | `ande-yvan.jpg` |

Exemple : remplacer `konan-yannick.jpg` met à jour le portrait existant. Ajouter `taty-hippolyte-landry.png` affiche son portrait sur sa fiche. Si vous changez d'extension, supprimez l'ancien fichier pour ne conserver qu'une image par personne.

Vercel doit être relié à ce dépôt et construire avec `npm run build`. Attendez la fin du déploiement pour voir la nouvelle photo. Les noms et biographies ne changent pas lorsqu'on ajoute un portrait.
